The 27-point SEO checklist for small businesses in India

By Saravanan M. Published: 15 June 2026 10 min read

You don't need a huge SEO agency or a ₹1 lakh monthly budget to move rankings. You need to do the right 27 things, in the right order, and be patient for 6 months. Here's the exact checklist we walk our own clients through.

// Sections

  1. Foundations (5 items)
  2. Technical SEO (6 items)
  3. On-page SEO (6 items)
  4. Content & keywords (5 items)
  5. Local SEO (3 items)
  6. Off-page & authority (2 items)

A / 1–5
Foundations

None of the fancy stuff matters if these five aren't done. Total time: about 2 hours.

01

Verify Google Search Console

Go to search.google.com/search-console, add your domain (use the domain property, not URL prefix), verify via DNS TXT record. This is your source of truth for how Google sees your site.

// ~15 min
02

Set up Google Analytics 4 (GA4)

Create a GA4 property. Add the measurement ID to your site's head. Verify data is flowing in real-time report. Set up 2–3 key events: form submits, WhatsApp clicks, phone clicks.

// ~20 min
03

Submit an XML sitemap

Generate a sitemap at /sitemap.xml. Include every important page, no duplicates. Submit it in Search Console. Add its URL to your robots.txt.

// ~15 min
04

Configure robots.txt properly

Allow Google to crawl your public pages. Block your admin, cart, thank-you, and test pages. Never block CSS or JS files — Google needs them to render pages correctly.

// ~10 min
05

Force HTTPS everywhere

Install SSL (free via Let's Encrypt if you're self-hosted). Force redirect all HTTP to HTTPS. Update internal links to use the HTTPS version. Check for mixed content warnings.

// ~30 min

B / 6–11
Technical SEO

Google can't rank pages it can't crawl or render properly. Total time: about 4 hours.

06

Pass Core Web Vitals

Aim for LCP under 2.5s, INP under 200ms, CLS under 0.1. Test with PageSpeed Insights. On Indian mobile networks, focus on: image compression, deferred JS, font loading, and hosting closer to your users.

// ~90 min
07

Fix crawl errors in Search Console

Open the "Pages" report in Search Console. Fix every 4xx and 5xx. Redirect old URLs with 301s. Remove crawl-blocked pages that shouldn't be blocked. Get "indexed" number climbing.

// ~45 min
08

Make the site mobile-friendly

Google indexes mobile-first. Test in Chrome DevTools at 375px width. Buttons should be tappable, text readable without zoom, no horizontal scroll. Fix layout issues on iPhone Safari specifically.

// ~60 min
09

Add structured data (JSON-LD)

At minimum: Organization on every page, LocalBusiness for local companies, FAQPage for FAQ sections, Article on blog posts, Product on e-commerce. Test each in Google's Rich Results Test.

// ~60 min
10

Set canonical tags

Every page needs a <link rel="canonical"> pointing to itself (or to the canonical version if it's a duplicate). No trailing slash mismatches. No mixed HTTP/HTTPS. No mismatched domain versions.

// ~30 min
11

Set hreflang if you serve multiple regions

If you have an English page and a Hindi one, use hreflang="en-IN", hreflang="hi-IN", and hreflang="x-default". Skip this if you only have one language version.

// ~15 min

C / 12–17
On-page SEO

The bits Google sees when it reads a page. Time: about 4 hours across your top 10 pages.

12

Write compelling title tags

50–60 characters. Include the primary keyword near the front. End with your brand. E.g. "Best Vada Pav in Pune — Ramesh Snacks". Every page unique. Avoid keyword stuffing.

// ~30 min for top 10 pages
13

Write meta descriptions that earn clicks

150–160 characters. Include a benefit + a CTA. Meta descriptions don't affect ranking directly but drive CTR — which does. Every page unique.

// ~30 min for top 10 pages
14

Structure headings correctly

One H1 per page, matching the query intent. H2s for main sections, H3s for sub-sections. Don't skip levels. Include target keywords naturally in H1 and 1–2 H2s.

// ~45 min
15

Optimise images

Compress every image before upload (Squoosh, TinyPNG). Serve in WebP or AVIF. Add descriptive alt text. Name files with keywords (blue-cotton-saree-handloom.webp, not IMG_0432.jpg).

// ~30 min
16

Internal link like you mean it

Every important page should be linked from 3+ other pages. Use descriptive anchor text (not "click here"). Link from high-authority pages (home, blog hub) to conversion pages (services, contact).

// ~45 min
17

Clean URLs

Short. Lowercase. Hyphens (not underscores). Include the keyword. No dates. No session IDs. E.g. /blog/ecommerce-website-cost-india — not /blog/2026/06/15/post-42?id=xyz.

// ~30 min if you're renaming existing URLs (redirect them!)

D / 18–22
Content & keywords

The single biggest lever for domain authority. Time: ongoing, 3–5 hours/week.

18

Do real keyword research

Free tools: Google's autocomplete, "People also ask", Search Console query report, Ubersuggest free tier. Paid: Ahrefs, Semrush. Focus on long-tail keywords with 100–1,000 monthly searches — easier to rank for.

// ~2 hours
19

Map keywords to search intent

Match each keyword to one of four intents: informational, navigational, commercial, transactional. Build the right kind of page for each. Don't try to sell on an informational page — Google won't rank it.

// ~1 hour
20

Publish pillar posts

Write 1,500-3,000 word guides on your top 3–5 keywords. Cover the topic exhaustively. Link out to authoritative sources. Include tables, examples, images. This one activity moves rankings more than anything else.

// ~4–8 hours per post
21

Refresh old content quarterly

Every 3 months, revisit posts that are ranking positions 5–20. Add fresh sections, update stats, improve examples. Change the "Last updated" date. Rankings often jump 3–5 positions from a good refresh.

// ~1 hour per post
22

Add FAQ sections

Every important page should have 4–8 FAQs at the bottom. Mark them up with FAQPage schema. Google may show them as rich results, dramatically improving CTR.

// ~30 min per page

E / 23–25
Local SEO

If you serve customers in a physical area, this section can drive 40–60% of your traffic. Time: 3–4 hours upfront + ongoing.

23

Claim & optimise Google Business Profile

Verify at business.google.com. Complete every field. Add 20+ photos (interior, exterior, team, products, work). Post updates weekly. Add booking links. Answer questions. This is the single highest-leverage local SEO action.

// ~2 hours setup
24

Nail NAP consistency

Your Name, Address, Phone must be identical across Google Business Profile, JustDial, Sulekha, IndiaMART, your website's footer, Facebook page, LinkedIn. Even punctuation differences hurt. Audit with Semrush Listing Management or manually.

// ~90 min
25

Get 5–10 real Google reviews in month 1

Ask happy customers directly. Send a short WhatsApp with the review link. Respond to every review (positive and negative). Aim for a 4.6+ rating with 20+ reviews to compete in local map results.

// Ongoing

F / 26–27
Off-page & authority

Everything you do to earn credibility from other sites. Slowest but longest-lasting impact.

26

Get listed on 15+ authoritative directories

JustDial, Sulekha, IndiaMART, TradeIndia, Clutch, GoodFirms, DesignRush (for agencies), Zomato/Swiggy (for F&B), MagicBricks (for real estate), Practo (for healthcare). Choose category-specific ones for your niche.

// ~4 hours upfront
27

Earn backlinks the honest way

Write guest posts on niche industry sites. Get quoted in journalist requests (HARO, Featured, SourceBottle). Sponsor a local event with your logo linked. Do a data study and publish it — that gets shared naturally. Avoid paid link farms — they'll penalise you.

// Ongoing
The truth about timelines None of this works in 4 weeks. Expect 3 months to see any movement, 6 months to see meaningful traffic, 12 months to see business impact. If someone promises page-1 rankings in 30 days for competitive keywords, they're either lying or using techniques that will hurt you long-term.
